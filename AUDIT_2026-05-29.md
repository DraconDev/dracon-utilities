## Security Deep Dive

### No `unsafe` blocks
Zero unsafe code in any production or test code.

### IndexLock Coordination
Both sync and warden use `O_EXCL` atomic file creation for `.git/index.lock`:
- Prevents TOCTOU races with git operations
- If git holds lock → warden/sync skip
- If warden/sync hold lock → git waits
- Same protocol git uses internally for inter-command coordination

### Secret Handling
- `load_secret()` checks env vars first, then `.env` files
- World-writable directory check prevents credential injection
- Age private keys use `Zeroize`/`ZeroizeOnDrop`
- Secrets never logged or serialized unencrypted

### Command Execution
All `std::process::Command` calls use the safe builder pattern:
```rust
std::process::Command::new("git")
    .current_dir(repo)
    .args(["add", "-A"])
    .output()?;
```
**No command injection vectors.**
