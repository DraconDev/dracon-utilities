# Fleet storage plan and canonical Dracon Sync roadmap

The general feature design and implementation roadmap now lives in the
standalone Dracon Sync repository:

[Dracon Sync object-storage roadmap](../../dracon-sync/docs/design/object-storage-roadmap-2026-10-01.md).

Platform, games, music, and video are evidence and pilot candidates. They do
not define universal placement rules or runtime dependencies. The roadmap
covers configurable policy, optional Warden integration, storage adapters,
durable scheduling, Git compatibility, recovery, migration, and release gates.

Status: proposed. No storage enrollment, bucket uploads, retention changes,
or history rewrites were performed while drafting the plan.
